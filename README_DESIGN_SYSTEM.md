# DISTAK ERP v2.7 — Design System v1.0

Atualização visual monocromática grafite, baseada na versão v2.7.

## Importante
Esta entrega foi criada como **atualização por sobreposição**. Copie os ficheiros para a pasta atual do projeto v2.7 e aceite substituir os ficheiros com o mesmo nome. Não apague os restantes ficheiros do projeto.

## Preservação das funções
- Nenhum ID de formulário, botão, tabela, diálogo ou módulo foi removido.
- Nenhuma função JavaScript ou ligação ao Supabase foi alterada.
- Dashboard desktop, clientes, obras, orçamentos, custos, pagamentos, fotografias e painel mobile continuam com a lógica anterior.
- As alterações concentram-se no CSS e em duas etiquetas visuais de versão no index.html.

## Paleta oficial
- Fundo: #F5F5F5
- Cartões: #FFFFFF
- Bordas: #E5E7EB
- Texto secundário: #6B7280
- Grafite: #374151
- Títulos e ações principais: #111827

## Instalação
1. Faça uma cópia de segurança da versão publicada.
2. Extraia este ZIP.
3. Copie o conteúdo para a raiz da versão v2.7.
4. Escolha **Substituir ficheiros existentes**.
5. Não escolha eliminar ficheiros que não existam neste ZIP.
6. Teste desktop e telemóvel antes de publicar.
